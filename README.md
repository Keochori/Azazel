Azazel is a 3D Game Engine built on DirectX11.

# How to run Azazel:
1. Download/Clone the repository.
2. Run "GenerateProjects.bat" to generate a solution.
3. Open and compile the solution.
4. You can find the compiled .exe in bin/{build-config}.
